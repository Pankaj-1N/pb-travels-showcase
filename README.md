# 🚌 P.B. Travels — Group Tour Coaches Website

A premium, modern single-page marketing and booking website built for **P.B. Travels**, a professional tour coach service based in Kolkata.

## 🔗 Live Project
* **Official Website**: [https://pbtravels.co.in](https://pbtravels.co.in)

---

## 🛠️ Tech Stack & Architecture
* **Frontend**: Next.js (App Router), React 19, Tailwind CSS v4, TypeScript
* **Animations**: Native IntersectionObserver triggers (pre-hydration optimized to prevent screen flashing)
* **Optimization**: Next.js automated Image Optimization with `sharp` for optimized WebP delivery
* **SEO**: Built-in JSON-LD Structured Schema Data (Google Local Business & Travel Agency markup), sitemap & robots generators

---

## 🌟 Features Implemented
* **WhatsApp Booking Integration**: Custom enquiry bar that translates client details (trip type, destination, dates, group size) into a pre-formatted native WhatsApp message link.
* **Infinite Logo & Fleet Carousels**: Custom CSS/JS infinite marquee showing the coach fleet.
* **Fully Responsive**: Mobile-first drawer navigation with blur-backdrop filters.
* **Custom Interactive Calendar**: Seamless cross-browser date-picker utility triggers.
